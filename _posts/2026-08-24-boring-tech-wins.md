Every time I've reached for the exciting new tool instead of the boring proven one, I've paid for it later — usually at 2am. This site itself is an example: plain Jekyll on GitHub Pages, no build pipeline to babysit, no dependencies to keep patched.

Novelty is a cost. Spend it deliberately.
